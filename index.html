Why it is built in pieces

A bot that does everything by default is a bot you spend a weekend undoing.

SeanBot ships as separate modules. Anti-raid and moderation are worth switching on before you tell anyone the server exists. Tickets, reaction roles, timezone roles, federation, analytics and the Wizard101 tools can wait until a member actually asks for one of them. Plenty of servers run this bot with four modules on and never touch the other forty.

Anti-Raid and AutoMod

Spam floods and brand new accounts get flagged as they arrive. A burst of a dozen joins in a short window trips the raid threshold, and the accounts get timed out and swept before a moderator has to notice. Canary Mode shows you the detections first, with quarantine, timeouts and message deletion left switched off until you trust the thresholds.

  • Canary Mode logs the detections without acting on them, so you can tune thresholds against your own traffic.
  • A stray spam message gets a lighter penalty than a coordinated raid. Repeat offenders escalate on their own.
  • Trusted roles are exempt, and every rule can be scoped to the channels that actually need it.

Support tickets stay private

A member opens a ticket from a button or a dropdown and lands in a private channel with the staff roles you pick. Whoever gets there first can claim it, so two moderators stop answering the same question twice. Notes added with /ticket staffsay never show up in the transcript the member can read, so your staff can be candid about a case.

Timezone roles

Members pick a continent from the panel or search for their city with /timezone set, and the matching regional role is applied for them. That role is what makes the rest of the bot usable: poll closing times, event reminders and raid sign-ups show up in each member's own local time rather than the server owner's.

If a member never sets one, nothing breaks. They just see event times in the server default like they always did.

Running two servers as one

Federation links servers you already trust. A channel in one becomes readable in the other, so an alliance-chat thread, a forum post, a Team-Up request or a leaderboard can be shared without asking everyone to join a second Discord.

Pairing is per channel, so a share can be as narrow as the one channel you both agreed on.

Polls and raid sign-ups

A poll is a question, a comma separated list of answers and an optional closing time. That is the whole setup. Raid sign-ups reuse the same panel with slot caps and waitlists, so when someone drops out the next person on the list gets the slot instead of a moderator having to reshuffle it by hand.

  • Up to 20 answers, each with its own numbered reaction, so voting is one click.
  • Closing time is optional. When it passes, the results post themselves.

Terms of Service & Privacy Policy

1. Terms of Service

By adding SeanBot to your Discord server or using our Web Dashboard, you agree to comply with Discord's Terms of Service and Community Guidelines. SeanBot is provided "as-is" without warranties of any kind.

2. Data Collection & Privacy

SeanBot collects only the data it needs to work:

  • Server IDs & Channel IDs: Stored to maintain server configuration settings.
  • User IDs: Stored for moderation points, warning history, LOA status, and timezone settings.
  • Command Usage Logs: Processed temporarily for analytics and error diagnostics.

3. Data Security & Storage

All database connections use encrypted channels. We do not sell, rent, or trade any user or server data to third parties.

4. Contact & Support

If you have questions regarding these terms or wish to request data removal, please contact our staff team through the support ticket system or official Discord community server.
