What people use it for

Keeping an eye on raids

Set join and spam rules, try them in Log Mode, then choose which actions SeanBot should take.

Knowing what happened

Choose a channel for edits, deleted messages, joins, leaves and role changes.

Planning across timezones

Members can set a timezone for timezone-aware tools and compare local times. Discord timestamps in event messages show each reader the time in their own locale.

Tickets, polls, events and staff settings sit alongside the moderation tools in SeanBot.

Use the parts you need

Most modules start on. Last-message tracking, staff lists and verification start off and can be enabled when you need them. Some modules rely on others, so check the dashboard's dependency notes before switching one off.

Anti-Raid and AutoMod

SeanBot adds join-rate rules, spam checks and configurable actions alongside Discord AutoMod. Start with Log Mode to see what the rules catch before turning on punishments.

  • Log Mode: logs detections without acting on them, so you can tune everything against your own server.
  • Configurable responses: choose a response policy by detection type; progressive timeouts are available for repeat offenses.
  • Safety: configure trusted-role bypasses; some detections also support channel-specific thresholds or multipliers.

Support tickets

Members open tickets from a panel button; channel access depends on the panel, the ticket participants and the server's support roles. Staff can claim a ticket to coordinate who handles it. Notes posted with /ticket staffsay appear in the ticket channel and are included in its generated transcript.

Timezone roles

Members can set their timezone with /timezone set and receive a matching role when automatic timezone roles are enabled. Scheduled TimePing events use an explicit timezone, then the organizer's saved timezone or server default; raid sign-up slots display Discord's localized timestamp.

Members who have not set a timezone can still use events; times continue to display as Discord timestamps.

Running two servers as one

Federation links servers you already trust. A channel in one becomes readable in the other, so an alliance-chat thread, a forum post, a Team-Up request or a leaderboard can be shared without asking everyone to join a second Discord.

Pairing is per channel, so a share can be as narrow as the one channel you both agreed on.

Questions we get

Is SeanBot really free?

Yes. There is no paid plan for SeanBot features.

What permissions does it ask for?

You approve the list on the invite screen and can edit it later under Server Settings. The access check at the end of setup names anything missing.

Can it replace the bots I already run?

It depends on which features you use. SeanBot can run alongside your other bots, so you can try it without replacing them.

Does it work for Wizard101 communities?

Yes. Damage, decks, pets, spells, stat caps and raid rosters ship alongside the general modules.

Do my members need to do anything?

No. Members do not need to set a timezone or open a ticket to use other features. What they see depends on which modules and settings their server enables.

What it keeps, and how to check

What it stores

  • Server and channel IDs, so your settings keep working.
  • User IDs for warnings, timeouts and timezone choices.
  • Command use, for analytics and error logs.

How to check

Run /permissions for an access audit, or /staff diagnose to see what is set and what still needs you. The full list is in the privacy policy.

Terms of Service & Privacy Policy

Last updated: July 2026

1. Terms of Service

By adding SeanBot to your server or signing in to the dashboard, you agree to follow Discord's Terms of Service and Community Guidelines. The bot is provided as it is, without warranties of any kind.

2. Data Collection & Privacy

SeanBot collects only the data it needs to work:

  • Server and channel IDs: Stored so your configuration keeps working.
  • User IDs: Stored for moderation points, warning history, leave of absence status, and timezone settings.
  • Command usage: Processed as it happens, for analytics and error diagnostics.

3. Data Security & Storage

Database connections are encrypted, and we do not sell, rent, or trade your data to anyone.

4. Contact & Support

Questions about any of this, or a request to remove your data, go to the staff team through the support tickets or the official Discord server. This tab is the short version; the full Terms of Service & Privacy Policy stands on its own page.
